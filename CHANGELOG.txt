CHANGELOG - Insights Desk / Reporteria
======================================

Proyecto: Reporteria operativa de soporte multicanal
Repositorio: HinataXL/Reporteria

Formato:
- Added: nuevas funcionalidades.

- Docs: documentacion y entregables tecnicos.


[v1.12.0] - 2026-08-06
----------------------
Branding, ventana flotante y experiencia de nueva conversacion.

Added:
- Se agrego el logo oficial de Insights Desk como asset estatico del proyecto.
- Se incorporo apertura de nueva conversacion en ventana flotante tipo Picture-in-Picture cuando el navegador lo soporta.
- Se agrego fallback automatico a popup normal si Document Picture-in-Picture no esta disponible.
- Se agrego comunicacion entre ventana flotante/popup y ventana principal para refrescar la data despues de guardar.

Changed:
- Se actualizo el branding en dashboard supervisor, dashboard agente, login, index/listado de conversaciones, panel admin y layout legacy.
- Se adapto la vista de nueva conversacion para modo flotante compacto.
- Se reemplazaron referencias visuales antiguas de Skill Soporte por Insights Desk.

Security:
- Se cambio X-Frame-Options de DENY a SAMEORIGIN para permitir que la propia aplicacion cargue la vista de nueva conversacion dentro del Picture-in-Picture, sin permitir embebido desde dominios externos.

Commits:
- 9043329 feat: agregar ventana flotante y actualizar branding
